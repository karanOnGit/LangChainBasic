## 🔍 Deep-Dive Breakdown

### 1. Conceptual & Pipeline Synthesis (`9.5/10` vs `4.0/10`)
* **ExplainGitHub**: Relies on basic keyword matching that breaks when queries do not exactly match file contents.
* **Karan RAG Engine**: Utilizes **LangChain LCEL**, **Dual-Query Fusion Retrieval**, and **Groq LPU (LLaMA 3.3 70B)** to comprehend full architectural workflows and explain complex end-to-end execution paths.

### 2. Abstract Reasoning & Nuance (`9.0/10` vs `5.0/10`)
* **ExplainGitHub**: Struggles with high-level evaluative questions.
* **Karan RAG Engine**: Accurately reasons through qualitative nuances, comparing model parameter scale, system throughput, and architectural trade-offs.

### 3. Source Citation & Verification (`9.0/10` vs `6.5/10`)
* **ExplainGitHub**: Displays generic high-level repository tabs without granular line-level grounding.
* **Karan RAG Engine**: Returns expandable verified citation cards showing the **exact document name, PDF page number, and original matching chunk excerpt**.

### 4. Input Ingestion & Flexibility (`9.5/10` vs `3.0/10`)
* **ExplainGitHub**: Strictly restricted to public GitHub repositories only.
* **Karan RAG Engine**: Features an extensible multi-modal ingestion hub supporting **PDFs, Word Docs (.docx), Markdown, Plain Text, CSVs, and Live Web URL Scraping** with on-the-fly vector store indexing.

### 5. Zero-Prompt / Instant UI UX (`6.5/10` vs `9.0/10`)
* **ExplainGitHub**: Excels at presenting pre-computed tabs immediately upon entering a repo URL.
* **Karan RAG Engine**: Provides interactive prompt chips and adaptive question starters, while focusing primarily on dynamic conversational depth and custom file Q&A.

### 6. Code Mapping & Execution Depth (`8.5/10` vs `7.0/10`)
* **ExplainGitHub**: Summarizes files in isolation without linking cross-module interactions.
* **Karan RAG Engine**: Maps high-level concepts directly to backend implementation files and returns concrete syntax-highlighted code implementations.
